# 勤怠管理システム

**飲食店（アルバイト・パート中心、複数店舗）向け**の Web 勤怠管理システムです。スタッフはスマホから打刻・希望シフト提出・概算給与の確認ができ、店長はシフト作成・承認・人件費管理を行えます。

- **構成**: Node.js (20 以上) + Express + SQLite（better-sqlite3）+ EJS（サーバーサイドレンダリング）
- **ビルド不要**・外部 DB 不要。`data/` ディレクトリに SQLite ファイル 1 つで動作します。

## 機能

### 権限
| 権限 | できること |
|---|---|
| 一般（スタッフ） | 打刻、シフト確認・希望提出、勤務表、申請、概算給与の確認 |
| 店長 | 上記 ＋ 担当店舗のスタッフの勤務状況・シフト作成・申請承認・勤務表・人件費 |
| 管理者（本部） | 全店舗の管理 ＋ 従業員・店舗・有給・休日・設定・操作ログ・CSV出力 |

### 飲食店向け機能
- **希望シフトの提出（スマホ対応）**: 4週間分の「出勤できる（時間帯指定可）／休み希望」をまとめて提出
- **シフト表**: スタッフ×日付のグリッドで希望と確定シフトを一覧。セルをクリックして編集、
  「希望から下書きを作成」「前の期間をコピー」「公開」に対応。日ごとの人数（必要人数との過不足）と予定人件費を表示
- **複数店舗・ヘルプ勤務**: 出勤時に店舗を選択、勤務中に「店舗を移動（ヘルプ）」。労働時間と人件費は実際に働いた店舗に按分
- **概算給与**: スタッフ本人が今月の概算給与（基本・時間外/深夜/休日割増・交通費）を確認可能
- **扶養内勤務の管理**: 年初からの概算収入と、従業員ごとに設定した年収の目安上限との比較（90%で警告）
- **人件費・売上**: 店舗別・日別の予定人件費（シフト）と実績人件費（打刻）、売上入力による人件費率
- **シフト基準の勤怠判定**: パート・アルバイトはシフトのある日が出勤予定日。遅刻・早退はシフト時刻で判定し、1日8時間超を残業として計算

### 従業員
- **打刻**: 出勤 / 退勤 / 休憩開始 / 休憩終了（複数回の休憩、日跨ぎ勤務に対応）
- **勤務表**: 月別の日次一覧と集計（労働時間・残業・深夜・休日労働・遅刻・早退・有給取得）、印刷対応
- **打刻漏れの通知**: 出勤記録なし・退勤打刻なしの日をダッシュボードに表示
- **申請**: 打刻修正申請（休憩時間含む）、休暇申請（有給・午前半休・午後半休・特別休暇・欠勤）、申請の取消
- **パスワード変更**（初回ログイン時は変更を強制）

### 管理者
- **本日の勤務状況**: 全員の出勤状況（勤務中・休憩中・退勤済・休暇・未出勤）、遅刻表示
- **申請の承認・却下**（コメント付き）、承認済み休暇の取消（有給は残日数に戻る）
- **月次集計・従業員別勤務表**、勤怠の直接修正・削除
- **CSV 出力**: 月次集計 / 日別明細（Excel で開ける BOM 付き UTF-8）
- **従業員管理**: 登録・編集・無効化、個別の始業/終業時刻・所定労働時間、仮パスワード発行
- **有給休暇管理**: 付与・調整と履歴（台帳方式）
- **休日カレンダー**: 国民の祝日を自動計算（振替休日・国民の休日対応）＋会社休日の登録
- **設定**: 所定労働時間、締め日（月末 / 任意日）、週休日、打刻の丸め、法定休憩の自動控除
- **操作ログ**: ログイン・打刻・修正・承認などを記録

### 計算ルール
| 項目 | 内容 |
|---|---|
| 労働時間 | 退勤 − 出勤 − 休憩（丸め設定を適用） |
| 法定休憩の自動控除 | 休憩打刻が 6時間超→45分、8時間超→60分 に満たない場合に不足分を控除（設定で無効化可） |
| 残業 | 出勤日の労働時間のうち所定労働時間を超えた分（半休の日は所定を半分にして計算） |
| 深夜 | 22:00〜翌5:00 の労働時間 |
| 休日労働 | 週休日・祝日・会社休日の労働時間（残業とは別集計） |
| 遅刻・早退 | 従業員ごとの始業・終業時刻との比較（半休の日は該当側を除外） |
| 日跨ぎ | 出勤日に帰属。退勤未打刻のまま24時間経過すると「退勤漏れ」 |

## セットアップ

```bash
npm install
npm start
```

ブラウザで http://localhost:3000 を開くと初期セットアップ画面が表示され、最初の管理者を作成できます。

### デモデータで試す

```bash
npm run seed:demo   # 空の DB にデモデータ（デモ食堂: 渋谷店・恵比寿店）を投入
npm start
```

パスワードはすべて `demo1234` です。

| ログインID | 役割 |
|---|---|
| `admin` | 本部（管理者） |
| `m001` | 渋谷店 店長 |
| `p001`〜`p003` | 渋谷店 アルバイト（`p001` は扶養内・年収目安あり） |
| `p004`〜`p005` | 恵比寿店 アルバイト |

### その他のコマンド

```bash
npm test                                       # テスト実行
npm run dev                                    # ファイル変更で自動再起動
npm run create-admin -- <ID> <氏名> <パスワード>  # 管理者の作成・パスワード再設定
npm run backup                                 # DB のバックアップ（稼働中でも可）
```

## 環境変数

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | `3000` | 待ち受けポート |
| `DATA_DIR` | `./data` | DB とセッション鍵の保存先 |
| `SESSION_SECRET` | 自動生成 | 未指定時は `DATA_DIR/.session_secret` に生成・保存 |
| `TRUST_PROXY` | 無効 | リバースプロキシ配下で `1` |
| `COOKIE_SECURE` | 無効 | HTTPS 運用時に `1`（Secure Cookie・HSTS を有効化） |
| `TZ` | `Asia/Tokyo` | タイムゾーン |

## 本番運用のポイント

- **HTTPS 必須**: nginx / Caddy などでHTTPS終端し、`TRUST_PROXY=1 COOKIE_SECURE=1` で起動してください。
- **常駐化**: systemd や pm2 などで `npm start` を常駐させます。
- **バックアップ**: `npm run backup` を cron で定期実行し、`backups/` を別の場所へ保管してください。
- **セキュリティ**: パスワードは bcrypt でハッシュ化、CSRF 対策、ログイン試行回数制限、CSP などのセキュリティヘッダーを設定済みです。

## ディレクトリ構成

```
src/
  server.js            起動エントリ
  app.js               Express アプリ構成（ミドルウェア・ルート）
  config.js            環境変数・パス
  db.js                SQLite 接続とマイグレーション
  lib/                 計算ロジック（calc）・日付・祝日・設定・CSV など
  services/            勤怠・申請・ユーザーの業務ロジック
  routes/              画面ごとのルーティング（auth / employee / admin）
  middleware/          認証・CSRF・レート制限
views/                 EJS テンプレート
public/                CSS / JS
scripts/               管理用コマンド
test/                  テスト（node:test）
```

DB スキーマを変更する場合は `src/db.js` の `MIGRATIONS` 配列の末尾に SQL を追加してください（既存要素は変更しない）。起動時に自動適用されます。
